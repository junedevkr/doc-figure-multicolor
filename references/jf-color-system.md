# doc-figure-multicolor 색 체계

박주이 교수 doc-figure v2.0(MIT)을 개인용으로 고친 색 체계. 원본 프리셋과 주색이 겹치지 않도록 ΔE(CIE76) 20 이상 떨어뜨렸고, 생김새도 공통으로 바꿨다(제목 왼쪽 + 짧은 색 표식, 둥근 사각 번호, 각진 칩).

## 1. 색 고르는 순서

1. 논문 제목·초록·키워드(없으면 서론 첫 절)를 읽고 연구 대상이 어느 계열인지 판단
2. `python3 scripts/jf_palette.py pick --text "<제목·초록·키워드>"`로 키워드 판별을 확인
3. 판단과 판별이 다르면 논문 내용 판단을 우선하고 이유를 한 줄로 남김. 두 계열 점수가 비슷하면 논문의 연구 질문이 겨누는 쪽을 고름
4. 사용자에게 고른 프리셋과 이유를 알림. 사용자가 색을 지정하면 그것을 따름
5. 한 논문의 PT·발표문·도식은 모두 같은 프리셋 하나로 통일
6. PT 테마 색은 `python3 scripts/jf_palette.py theme <프리셋>`의 JSON(제목·강조·본문·패널·선 색과 tone 6색)을 그대로 씀

## 2. 내용 계열 7가지

| 프리셋 | 계열 | 주색 | 이런 논문 |

| `jf-tech` | 기술·혁신 | 남보라 `#33289A` | AI·디지털·플랫폼·R&D·신흥기술·기술영향평가 |
| `jf-method` | 방법론·분석 | 자홍 `#8C1F5E` | 분석틀·모형·계량·측정·과학계량·평가방법 |
| `jf-risk` | 보건·안전·위험 | 진홍 `#A51E45` | 위험·불확실성·안전·보건·재난·윤리 |

## 3. 흑백톤

| 프리셋 | 쓰는 때 |
|---|---|
| `jf-mono-ink` | 흑백. 검정 한 가지와 흰 바탕, 직각, 강조 상자는 외곽선. 흑백 인쇄·제출용 |
| `jf-mono-gray` | 그레이스케일. 중립 회색 단계, 옅은 회색 바탕, 모서리 6px |

`pick`에 `--mono ink|gray`을 붙이면 같은 판별로 흑백 프리셋을 고른다. 사용자가 흑백을 요청하거나 흑백 인쇄 제출이면 흑백톤을 쓴다.

### 쨍한 컨셉 `jf-pop`

| 항목 | 값 |
|---|---|
| 색 | main 전기 남색 `#3D3BF3` · sub 핫핑크 `#E6247A` · go 에메랄드 `#00A06A` · wait 주황(흰 글자 대비 3.0으로 낮춤) · stop 빨강 `#E5243B` · mute 회색 `#6B7280` |
| 모양 | 흰 페이지 + 짙은 바깥 배경 `#17171D`, 묶음·카드·띠 테두리 없음, 모서리 18~26px, 묶음 머리는 색 글자, 제목은 검정 + 핑크 짧은 표식 |

| 쓰는 때 | 계열 색이 관공서 보고서처럼 보일 때, 발표용으로 선명하게 갈 때 |

## 3-2. 출처 팔레트와 컬러차트

- 컬러차트 28색은 모두 프리셋이 있다: P-01 `jf-timeless`, P-02 `jf-serene`(손으로 다듬음), P-03~P-28 `jf-p03`~`jf-p28`(`jf_palette.py build`가 원본 색 그대로 자동 생성)

- 새 컬러 컨셉은 직접 정하지 않고 공개된 프레젠테이션 팔레트에서 사용자가 고른다
- `references/jf-source-palettes.json`: 팔레트 28개(P-01~P-28, 일부는 12색 테마 포함), 색상 코드는 공개된 값 그대로
- `python3 scripts/jf_color_chart.py -o 컬러차트.html`: 팔레트마다 미니 슬라이드 미리보기 + 색 칩, 카드를 눌러 고르고 번호 복사
- 고른 번호로 `jf-palettes.json`의 `concepts`에 컨셉을 추가하고 `build` → `check`

## 4. 도식 안에서 색이 맡는 뜻 (board `tone`)

논문 요소를 아래처럼 tone에 맞춘다. 색은 장식이 아니라 구분이다.

| tone | 뜻 | 논문 요소 |
|---|---|---|
| `main` | 핵심 개념·본체 | 논문의 중심 개념, 연구자의 분석 결과 |
| `sub` | 하위 개념·보조 | 하위 개념, 구성요소, 참여자의 해석 |
| `go` | 결과·산출 | 결과, 결론, 저자의 제안 |
| `wait` | 조건·주의 | 조건, 판단지점, 한계, 가정 |
| `stop` | 문제·위험 | 문제, 실패, 위험, 탈락 |
| `mute` | 기존·배경 | 선행연구 소개, 배경, 기존 제도 |

연구자의 분석 결과·참여자의 해석·선행연구·저자의 제안을 다른 tone으로 칠해 구별이 그림에서도 보이게 한다. 한 그림에 진한 면은 머리띠·이름표·핵심 한 곳만 둔다.

## 5. 고치는 법

- 색·키워드는 `references/jf-palettes.json`만 고친 뒤 `python3 scripts/jf_palette.py build`
- `python3 scripts/jf_palette.py check`로 흰 글자 대비 4.5 이상, 원본·내 계열끼리 ΔE 20 이상을 확인
- `python3 scripts/jf_palette.py preview`로 `examples/preview/jf-palettes.html` 갱신
- 토큰 이름은 원본 `house.css`와 같은 집합을 유지(빌드가 house.css를 틀로 값만 바꿈)
